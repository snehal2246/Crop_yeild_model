# Crop Yield Prediction Using Linear Regression

This project uses Machine Learning and Linear Regression to predict crop yield based on important agricultural factors such as rainfall, soil quality, farm size, sunlight hours, and fertilizer usage.

The project includes data preprocessing, exploratory data analysis, simple and multiple linear regression, model evaluation using MSE, MAE, and R² score, and crop yield prediction using user input.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Scikit-learn, Jupyter Notebook.
